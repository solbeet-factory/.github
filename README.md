# .github

Archivos de salud comunitaria por defecto de la organización: plantillas de
issue y de pull request que heredan los repos que no tienen las suyas.

GitHub exige que este repositorio sea público para que las plantillas se
apliquen a los demás repos (los repos que heredan pueden ser privados). Por eso
acá viven **solo las plantillas**; el tooling del flujo (scripts del reporte,
labels, telemetría) vive en un repo privado.
